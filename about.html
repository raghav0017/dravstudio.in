About the studio

A small studio with strong opinions about details.

We are designers who write code and developers who care about type, working as one team from the first sketch to the last deploy.

We started DRAV to close the gap between the mockup and the live site.

Too many projects lose their quality in the handoff. The design is sharp, the build is approximate, and nobody owns the difference. We set up DRAV so that the same people draw it and ship it.

That means we prototype in code early, name every color and space once, and test on real devices before launch. It also means we turn down projects where nobody on the client side can make decisions.
